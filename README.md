# Secure IoT Monitoring System

## Overview
Secure MQTT-based sensor monitoring system uses TLS encryption to protect sensor data

## Features
- TLS Encryption
- Sensor Authentication
- JSON Data Exchange
- Dashboard Monitoring

## Technologies
- Python
- MQTT
- Mosquitto
- TLS

## How to Run
1. Install requirements
2. Start Broker
3. Run Publisher
4. Run Subscriber
